# Model and effort compatibility

Astra-Ultra accepts provider model identifiers and these effort labels:

- Models: `gpt-4o`, `gpt-4o-mini`, `o1`, `o1-mini`, `o3-mini`, and `o3`.
- Effort: `none`, `low`, `medium`, `high`, `max`, and `xhigh`.

The host provider determines which model and effort combinations are valid.
